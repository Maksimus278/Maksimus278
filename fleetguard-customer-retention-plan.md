# FleetGuardAI Customer Retention Plan

**Product:** FleetGuardAI (www.FleetGuardlogistics.com)  
**Audience:** Trucking fleets needing DOT compliance, document storage, expiration tracking, and FMCSA record monitoring  
**Plans:** Starter ($99) · Growth ($199) · Fleet ($299) · DOT Record Monitor add-on ($29)

---

## 1. Retention goal

Keep paying fleets active because the product prevents downtime, audit stress, and expired credentials — not because canceling is hard.

**North-star metrics**

| Metric | Target direction |
| --- | --- |
| Trial → paid conversion | Raise |
| Day-30 and Day-90 retention | Raise |
| Monthly churn (logo + revenue) | Lower |
| % accounts with ≥1 login / 7 days | Raise |
| % accounts with documents uploaded + dates tracked | Raise |
| Expansion (Starter → Growth/Fleet, Monitor attach rate) | Raise |

---

## 2. Why fleets churn (and what to do)

| Churn driver | What it looks like | Retention response |
| --- | --- | --- |
| Failed activation | Trial ends with empty dashboard | Guided setup + “first value” checklist |
| Low habit | Login only when something expires | Proactive alerts + weekly digest |
| “Spreadsheets are fine” | Value not felt until audit/stop | ROI stories + near-miss reminders |
| Price sensitivity (small fleets) | Cancel after quiet months | Starter fit messaging + annual option |
| Support friction | Can’t find a file / don’t trust data | Fast human help + clear next steps |
| Feature gap | Need integrations, multi-user, reports | Upgrade path + roadmap previews |

---

## 3. Retention by lifecycle stage

### A. Trial (Days 0–14) — convert by proving value early

Card-required trials still churn if setup never finishes. Optimize for **time-to-first “needs attention” insight**.

**Activation definition (must complete before Day 7)**

1. Add DOT number / company  
2. Upload ≥3 core documents (e.g., CDL, medical card, insurance)  
3. Confirm ≥1 tracked due date  
4. Open dashboard and clear or acknowledge ≥1 alert  

**Playbook**

| Day | Trigger | Action |
| --- | --- | --- |
| 0 | Signup | Welcome email + 3-step setup link; in-app checklist |
| 1 | No DOT number | Reminder: “Add your DOT number to connect your FMCSA record” |
| 2–3 | No uploads | Short video / tips: upload CDL + medical card first |
| 5 | Partial setup | Offer 15-min setup call (Growth/Fleet) or chat (Starter) |
| 10 | Active but unused features | Highlight expiration alerts + DOT check |
| 12–13 | Trial ending | Summary of what’s tracked + what would expire unprotected |
| Cancel intent | Cancel click | Exit survey + one-click “pause” or extend 7 days if activated |

**Product nudges**

- Empty-state CTAs that name the next file to upload  
- Auto-extract review prompts so uploads feel fast  
- Soft paywall preview: “After trial, reminders keep running for X drivers”

---

### B. Onboarding (first 30 paid days) — make compliance habit sticky

**Week 1:** Complete driver/file coverage for the active roster  
**Week 2:** Turn on email alerts; invite a second user on Growth/Fleet  
**Week 3:** Review CSA / DOT record once with the customer  
**Week 4:** Send “compliance snapshot” (expiring in 30/60/90 days)

**Success signal:** Customer renews a real credential using a FleetGuard reminder (or avoids a last-minute scramble). Capture that win in-product (“You renewed before expiry”).

---

### C. Steady state (Month 2+) — stay visible without noise

| Cadence | Channel | Content |
| --- | --- | --- |
| Real-time | Email / in-app | Expiration & DOT Record Monitor changes |
| Weekly | Email digest | What’s due, what’s missing, what changed |
| Monthly | In-app / email | Compliance health score (simple: Ready / Attention / Urgent) |
| Quarterly | Email / call (Fleet) | Usage review + upsell to Monitor or higher tier |

**Rule:** Alerts must be actionable. Prefer fewer, clearer notices over volume.

---

### D. At-risk & save motions

**At-risk signals**

- No login in 14+ days  
- No document activity in 30+ days  
- Alerts ignored repeatedly  
- Payment failure  
- Downgrade or cancel started  
- Fleet size declining in product data  

**Save offers (use sparingly, match segment)**

| Segment | Offer |
| --- | --- |
| Activated, quiet month | Concierge document cleanup call |
| Price objection (Starter) | 2 months at discounted rate or annual prepay discount |
| Feature objection | Temporary Growth trial features for 14 days |
| Leaving for competitor | Exit interview + win-back at Day 30/60 with “what’s new” |

**Dunning (failed payments)**

- Day 0, 3, 7, 10: clear emails with update-card link  
- Grace period with read access to documents (builds trust; don’t lock people out of their own files immediately)  
- Soft lock of *new* uploads / Monitor before hard cancel

## 4. Product-led retention levers

Build retention into the product, not only into email.

1. **Compliance health dashboard** — one glance: missing files, due soon, DOT changes  
2. **Expiration calendar** — 30/60/90-day view fleets can share with owners  
3. **Audit / review mode** (Growth+) — folder-ready export for roadside or insurance reviews  
4. **DOT Record Monitor attach** — daily FMCSA checks create ongoing “must stay subscribed” value at $29  
5. **Team seats** — more users → higher switching cost and coverage when one person leaves  
6. **Integrations** (Fleet) — ELD / TMS links reduce duplicate entry and deepen lock-in  
7. **Document AI trust loop** — high-accuracy extract + easy correct → less typing, more stickiness

## 5. Service & relationship retention

| Segment | Support model |
| --- | --- |
| Starter | Email + help center; response SLA within 1 business day |
| Growth | Priority email/chat; setup help on request |
| Fleet | Dedicated support; quarterly check-in; custom review steps |

**Trust builders for trucking buyers**

- Plain-language product copy (already on-brand — keep it)  
- Clear limits of FMCSA public data (insurance/OOS unavailable — say so upfront)  
- Security FAQ + data ownership: “Your files leave with you if you cancel”  
- Optional annual compliance webinar for customers only

## 6. Pricing & packaging retention

| Tactic | Purpose |
| --- | --- |
| Annual plans (e.g., ~2 months free) | Lower monthly churn; improve cash flow |
| DOT Monitor bundle discount with Growth/Fleet | Raise attach rate; daily value loop |
| Soft seat/truck overage warnings before hard blocks | Prevent angry churn from growth |
| Grandfather early customers for 12 months on price | Protect loyalty during raises |
| “Pause” (30–60 days) for seasonal fleets | Prefer pause over cancel |

---

## 7. Expansion as retention

Happy customers who grow with you churn less.

**Natural upgrade paths**

- Starter → Growth when they need full CSA areas, reports, or more team members  
- Growth → Fleet at ~50 trucks or when they want integrations / unlimited seats  
- Any plan → DOT Record Monitor after first “status change” education moment  

**Trigger-based upgrade prompts**

- Hitting truck/driver limits  
- Attempting a Growth-only report  
- Viewing DOT record frequently without Monitor  
- Multiple users sharing one login (invite prompt)

## 8. Measurement & operating rhythm

**Weekly**

- Trial activation funnel (DOT → upload → date → alert)  
- New paid logos, cancellations, failed payments  
- Support tickets tagged `churn-risk` / `billing` / `setup`

**Monthly**

- Logo churn %, revenue churn %, net revenue retention  
- Cohort retention by plan and fleet size  
- Alert engagement (open / act rates)  
- Monitor attach rate  

**Quarterly**

- Win/loss & cancel reason themes  
- Feature requests tied to retained vs churned accounts  
- Roadmap bets that protect retention (not only acquisition)

## 10. Messaging principles (on-brand)

FleetGuard already sells clarity, not jargon. Retention copy should match:

- **Lead with the next action:** “Renew medical cards before Mar 12”  
- **Avoid fear spam:** urgency only when dates are real  
- **Respect owner time:** short emails, one CTA  
- **Be honest about data limits:** public FMCSA ≠ full compliance magic  

**Example retention email subject lines**

- “3 items need attention before next week”  
- “Your trial ends in 2 days — here’s what’s already tracked”  
- “DOT record change detected for [Carrier]”  
- “Quiet month? Your expirations are still covered”  

---

## 11. Summary

FleetGuardAI retains customers when fleets **set up once, get reminded before problems, and trust the dashboard as the source of truth**. Prioritize:

1. **Activation in trial** (DOT + documents + dates)  
2. **Proactive, accurate alerts** (habit without noise)  
3. **Human help for stuck fleets** (especially Growth/Fleet)  
4. **Monitor + team + integrations** (structural stickiness)  
5. **Fair billing recovery and pause options** (save before cancel)

Treat retention as a product + ops system measured weekly — not a one-time campaign.
